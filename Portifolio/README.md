# 💻 Mini Projeto e Estudos — Perfil Profissional (.NET / Windows Forms)

Aplicação desktop desenvolvida em **C#** com **Windows Forms (.NET Framework 4.8.1)** para apresentar meu perfil profissional, formação acadêmica, projetos e estudos práticos de forma interativa.

---

## 🚀 Funcionalidades
- **Tela Principal (Apresentação):** Exibe resumo profissional, tecnologias dominadas, ferramentas e formação acadêmica.
- **Navegação entre Telas:** Botões dedicados para acessar as seções de **Projetos** e **Estudos C# .NET Framework**.
- **Mensagem de Boas-vindas:** Saudação interativa ao iniciar a aplicação.

---

## 🛠️ Tecnologias Utilizadas
- **Linguagens:** C#, SQL
- **Framework:** .NET Framework 4.8.1 (Windows Forms)
- **Banco de Dados:** MySQL
- **Ferramentas e Versionamento:** Visual Studio, Git e GitHub

## ⚙️ Como Executar o Projeto
1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Abra o arquivo de solução `Mini_Projeto_e_Estudos.sln` no **Visual Studio**.
3. Pressione **F5** (ou clique em **Iniciar**) para compilar e executar a aplicação.
